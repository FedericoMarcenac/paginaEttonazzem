Ettonazzem Express

Sitio web desarrollado para Ettonazzem, un comercio dedicado a la venta de artículos de librería comercial y escolar, productos de computación y artículos descartables.

El objetivo del proyecto es presentar el negocio en Internet, organizar sus principales categorías de productos y facilitar el acceso de los clientes a la información del comercio.

Tecnologías utilizadas

HTML5

CSS3

Bootstrap 5.3.1

Git

GitHub Pages

Características

Página principal con identidad visual del comercio.

Navegación entre las diferentes secciones del sitio.

Organización de productos por categorías.

Sección de información sobre el negocio.

Acceso directo al contacto mediante WhatsApp.

Diseño adaptable a diferentes tamaños de pantalla.
